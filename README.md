# Koke Arena

Windows x64向けのゲーム配布ページです。

**[Windows版をダウンロード](https://github.com/Koke-Niwa/KokeArena-releases/releases/download/update-1/KokeArena-Windows-update-1.zip)**

1. ダウンロードしたZIPをすべて展開します。
2. `KokeLauncher.exe` を起動します。
3. 更新確認が終わったら「ゲームを起動」を押します。

ゲーム本体と数値の更新は、ランチャーが次の起動時に取得します。GitHubへのログインや.NETの追加インストールは不要です。通信できない場合は保存済みの版でプレイできます。

更新前の実行ファイルだけを持っている場合は、初回だけ上記のランチャー付き版をダウンロードしてください。

[更新履歴を見る](https://github.com/Koke-Niwa/KokeArena-releases/releases)
